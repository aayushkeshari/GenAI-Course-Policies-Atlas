Generative AI in CS departments

Synthetic data: real university names are attached to invented policies and statements. Nothing here describes what these schools actually do.

This project studies, with synthetic data, how US computer science departments permit, encourage and talk about generative AI, with a focus on software engineering courses. Claude Code wrote the code from specs that a human supervisor owned, and the logs of that work are published too.

  • Findings dashboard

    Policies by course level, department rhetoric and tone over time, software engineering vs other courses, and assessment changes.

    G1 · data and analysis

  • Validation explorer

    Test runs, requirement traceability, coverage, fault injection, and whether the analysis recovers the planted effects.

    G2 · correctness evidence

  • Contribution timeline

    A timestamped record of prompts, Claude's responses, commits, spec edits and reviews, split into human and agent work.

    G3 · who did what

  • Token usage

    Tokens by phase and prompt, context size across /clear and /compact, and the clear/compact experiment.

    G4 · token usage

  • Evaluation & reflection

    The supervisor's own evaluation against the goals, and a reflection on agentic versus AI-assisted development.
